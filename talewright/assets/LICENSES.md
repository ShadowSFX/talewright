# Licenses of Talewright's default assets

Talewright ships no third-party art, sound or data by default (D-011). Every default asset is generated by code in
this repository and is an original work of the Talewright contributors; none is derived from RPG Maker's runtime
packages or any other engine's assets, and the layouts (tile size, autotile and wall sheets) are Talewright's own
(`plan/specs/05_maps_tiles.md`).

| Path | Made by | License |
|---|---|---|
| `talewright/assets/generated/**` | `talewright/tools/generate_assets.py` and `talewright/tools/asset_gen/` (drawn from code and fixed seeds; `manifest.json` lists every file with the hash of its pixels) | [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/): public domain dedication, use for anything without attribution |

When a third-party asset is ever added, give it its own row: the path, the author and source URL, and the exact
license (CC0 only by default, D-011).
